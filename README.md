## How to run it: 
## Getting Started
### Prerequisites
- Git
- VS Code (recommended)
- Live Server extension for VS Code
### Installation
1. Clone the repository: `git clone [my repository](https://github.com/nguyennn1212/portfolio-site-v1)]`
2. Open the project in VS Code
3. Install the Live Preview extension
4. Right-click on `index.html` and select "Open with Live Server"
* If you want to run the project locally:
  + Use Git to clone this project.
  + I used [Microsoft Live Preview](https://marketplace.visualstudio.com/items?itemName=ms-vscode.live-server) to have a preview of how my site look like.
  + You can make any change to this project using HTML and CSS. Or simply use this as the base to create your own website!
  + After you're happy with how the project looks, you can host it as a live site like I did. Using GitHub.
